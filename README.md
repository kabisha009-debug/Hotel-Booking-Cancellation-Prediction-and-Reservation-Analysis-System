Hotel Booking Cancellation Prediction and Reservation Analysis System

Project Overview

Exploratory Data Analysis and Data Preprocessing of the Hotel Booking Demand dataset to understand booking patterns, analyze cancellation trends, handle missing values and duplicates, and prepare data for Machine Learning.

The project also includes a trained classification model integrated with a FastAPI backend to predict hotel booking cancellations.

Project Workflow

1.Dataset Collection: Collected the Hotel Booking Demand dataset containing historical hotel reservation records.
2.Data Cleaning: Handled missing values and duplicate records.
3.Exploratory Data Analysis (EDA): Analyzed booking patterns and cancellation trends using visualizations and statistical methods.
4.Data Preprocessing: Prepared the dataset by handling categorical variables and transforming features.
5.Model Training: Trained a Machine Learning classification model using the preprocessed data.
6.Model Evaluation: Evaluated model performance using test data.
7.Model Saving: Saved the trained model and preprocessing objects using Joblib.
8.FastAPI Development: Integrated the saved Machine Learning model with a FastAPI backend.
9.Prediction: Developed an API endpoint to predict whether a hotel booking will be cancelled.
